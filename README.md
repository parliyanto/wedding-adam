# 💒 Digital Wedding Invitation – Adam & Chi

An elegant, modern, and interactive digital wedding invitation website designed to deliver a beautiful and seamless online experience for guests.

🔗 **Live Demo:**  
https://wedding-adam-chi.vercel.app/

---

## 📌 Overview

This project is a fully responsive digital wedding invitation website created to transform traditional printed invitations into a modern online experience.

The website presents wedding information in a structured, aesthetic, and emotionally engaging way, allowing guests to easily access event details through any device.

---

## 🎯 Purpose

The purpose of this project is to:

- Provide a stylish digital wedding invitation solution
- Deliver a smooth and elegant user experience
- Demonstrate frontend design and UI capability
- Replace physical invitations with a shareable web-based format
- Showcase interactive web design skills

This project represents a real-world implementation of a digital invitation concept.

---

## ✨ Key Features

- Elegant hero section with couple introduction
- Smooth scrolling navigation
- Wedding event details (date, time, location)
- Interactive layout structure
- Responsive design (mobile & desktop)
- Modern typography and romantic color palette
- Shareable URL-based invitation
- Clean and aesthetic UI presentation

---

## 🎨 Design Philosophy

The design emphasizes:

- Minimalist elegance
- Romantic and warm visual tone
- Clear information hierarchy
- Smooth user journey from opening to event details
- Mobile-first experience

The layout balances emotional storytelling with functional clarity.
